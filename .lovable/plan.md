
## الهدف
إضافة زر "استيراد من Excel" في صفحة إدارة المنتجات (`/admin/products`) لرفع ملف `.xlsx` يحتوي على 5 أعمدة، واستخراج عمودَي **اسم المادة** و**الرصيد** فقط، ثم إنشاء منتج جديد لكل صف ببيانات افتراضية فارغة.

## التغييرات

### 1. تثبيت مكتبة قراءة Excel
- إضافة `xlsx` (SheetJS) إلى المشروع لقراءة ملفات `.xlsx` في المتصفح.

### 2. تعديل `src/pages/admin/Products.tsx`
- إضافة زر جديد بجانب "إضافة منتج" باسم **"استيراد Excel"** مع أيقونة رفع.
- عند الضغط يفتح Dialog فيه:
  - منطقة سحب وإفلات + زر اختيار ملف `.xlsx` / `.xls`.
  - بعد اختيار الملف: قراءة أول ورقة (Sheet) وعرض **معاينة** بعدد الصفوف والأعمدة المكتشفة.
  - **خيار**: تجاهل الصف الأول (Header) — مفعّل افتراضياً.
  - حقلان لاختيار رقم العمود لـ "اسم المادة" (افتراضي: العمود 2) و"الرصيد" (افتراضي: العمود 3) مع معاينة لأول 5 صفوف.
  - زر **"استيراد"** + زر إلغاء.
- منطق الاستيراد:
  - لكل صف: قراءة قيمتي الاسم والرصيد.
  - تخطّي الصفوف الفارغة أو التي لا تحتوي على اسم.
  - تحويل الرصيد لرقم صحيح (`parseInt`)؛ إذا فشل يصبح 0.
  - بناء payload لكل صف:
    ```
    {
      name_ar: <اسم المادة>,
      name_en: <اسم المادة>,   // نفس القيمة (يعدّلها لاحقاً يدوياً)
      stock: <الرصيد>,
      price_iqd: 0,
      price_wholesale_iqd: 0,
      price_dealer_iqd: 0,
      is_active: true,
      brand: null, category_id: null, subcategory: null,
      desc_ar: null, desc_en: null,
      image_url: null, datasheet_url: null, datasheet_name: null
    }
    ```
  - إدراج دفعي عبر `supabase.from("products").insert(rowsArray)` (دفعات 200 صف لتجنّب الحدود).
  - شريط تقدّم + Toast بالنتيجة: "تم استيراد X منتج، فشل Y".
  - استدعاء `refetch()` بعد الانتهاء لتحديث الجدول.

### 3. ملاحظات تقنية
- المكتبة `xlsx` تُحمَّل عند فتح الـ Dialog فقط (dynamic import) للحفاظ على أداء الصفحة.
- لا تغييرات على قاعدة البيانات — جميع الأعمدة المطلوبة موجودة وتقبل قيماً افتراضية.
- لا تأثير على بقية صفحات الموقع.

### 4. الترجمة
- إضافة مفاتيح ترجمة في `src/i18n/translations.ts`: `import_excel`, `import_products`, `select_excel_file`, `column_name`, `column_stock`, `skip_header`, `preview`, `imported_success`, `import_failed_some`.

## ما لن يتم
- لن نستورد: رمز المادة، معدل الكلفة، قيمة الرصيد (حسب طلبك).
- لا توجد منطق تحديث للمنتجات الموجودة — فقط إنشاء جديد. (يمكن إضافته لاحقاً إن رغبت).
